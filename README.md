Smart CivicConnect is a full-stack web application that enables citizens to report public infrastructure issues such as potholes, damaged roads, broken street lights, garbage accumulation, water leakage, and drainage problems.

Citizens can upload images, provide issue details, and mark the exact location using Google Maps. The system allows other users to like/upvote reported issues, helping the government identify high-priority problems and respond quickly.

The application also includes a reward system that encourages citizens through points, badges, and awards for genuine contributions.
